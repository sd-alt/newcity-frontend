# 四中心与智能任务规划前端说明

## 入口与路由

顶部只显示任务中心、资源中心、业务中心和应用中心四个一级入口。旧六中心 URL 仅保留重定向兼容，不再作为导航、首页目录或全局搜索结果的规范路径。

| 中心 | 规范路由 | 主要页面 |
| --- | --- | --- |
| 任务中心 | `/tasks` | 基础指标体系、六层手工建模、任务指标体系、版本追溯 |
| 资源中心 | `/resources/*` | 传感器详情与八类档案、观测数据、算法服务、知识库 |
| 业务中心 | `/business*` | 任务、资源匹配评分、方案评价、执行与成果 |
| 应用中心 | `/application*` | 场景任务、手动/AI/多 Agent、GIS 与统计 |

## 使用流程

应用中心选择场景，填写自然语言需求、时间、频次并可在 Cesium 地图绘制多边形。选择手动模式时，系统立即生成需求与任务草案，点击“继续配置任务指标”进入任务中心，选择本人任务草案并绑定任务指标体系；确认后在业务中心完成资源匹配、方案、发布、下发、执行和成果汇集。

AI 辅助和多 Agent 模式会显示阶段轨迹、待确认节点、工具名称、业务数据来源和工件。页面提供暂停、恢复、重试、取消、人工接管和补充需求操作；不展示模型内部思维链。模型未配置时，运行停在人工接管状态，手动页面仍可用。

顶部“使用引导”直接说明操作顺序：先在应用中心填写需求，再到任务中心配置指标、资源中心检查资源、业务中心制定方案。引导首次进入自动展开，可隐藏并在当前浏览器记忆，也可随时从顶部入口重新打开；引导中的中心节点和当前页面按钮均可直接跳转。

## 四中心信息层级

- 首页按常用操作顺序排列四中心，不再用机械编号；运行判读只保留资源、数据和任务三类需要关注的业务状态。
- 资源中心将卫星在线接入和移动平台轨迹接入收进默认折叠的“高级接入”，平台与传感器日常管理优先展示。
- 应用中心 GIS 页只保留一份图层账本，统一控制传感资源、监测数据、观测任务和指标实例，避免同一组数字与开关重复出现。
- 各中心继续复用公共 Cesium 工作区；统计和状态用于回答“是否需要处理、下一步去哪里”，不作为装饰性数字卡片。

## AI 助手设置

右下角 AI 助手提供“对话”和“设置”两个视图。设置页只读展示后端返回的模型名称、运行模式和就绪状态，并允许保存两项浏览器偏好：综合感知任务的默认方式（手动、AI 辅助或多 Agent），以及是否在任务运行页显示工具调用、数据来源和耗时。

模型地址、模型名称的服务端配置和 API Key 继续由后端环境变量管理；浏览器不会保存、回显或提交密钥。保存偏好后，已经打开的综合感知任务页会立即同步，刷新后仍保持选择。

## 多指标协同评估

业务中心沿用规划工作台第 8 步“满足度评估”展示协同观测认知，不新增一级入口。多指标任务会显示：

- 指标满足数量、总体并集覆盖、多指标共同覆盖和指标覆盖错位。
- “共同覆盖—覆盖错位—未覆盖”空间比例带。
- 竞争、互补、增强、协作关系数量及资源组合计算依据。
- 完整计算证据，内部 WKT 字段继续过滤，不直接暴露给业务用户。

执行评估或刷新后重新拉取评估结果时，地图优先绘制多指标共同覆盖及其缺口；单指标任务继续绘制原有总体覆盖和缺口。

评估摘要带有可隐藏的判读说明，按“任务判定、空间质量、资源组合”解释阅读顺序。隐藏状态保存在当前浏览器，页面仍保留“查看判读说明”入口。

## 传感器详情与八类档案

资源中心将原“传感器八元组”入口呈现为“传感器详情”。传感器资源列表可直接打开指定资源档案，页面先显示当前传感器、所属平台、状态和档案完整度，再按身份与归属、属性能力、时空参考、地理定位、历史、联系、约束和接口八类并列维护。八类档案不是必须依次完成的八步，空白类别应在获得真实资料后补充。

详情页的使用说明可以隐藏，隐藏状态保存在当前浏览器，并可通过“查看档案说明”重新展开。

## 视觉与交互约束

界面采用岩层灰、测绘青和预警琥珀的地学作业台方向，Cesium 地图继续作为公共空间工作区，Agent 阶段轨迹是唯一强视觉元素。页面避免大面积渐变、频繁动画、多层弹窗和额外中心入口，并包含加载、空数据、失败提示、表单校验、保存反馈、搜索、分页与删除确认。
