# 传感器完整档案交互说明

资源中心现有导航保持不变。用户可以从传感器资源列表、观测能力管理或地图抽屉进入传感器完整档案，入口最多两次点击即可到达目标分区。

## 入口与返回

资源列表提供查看、编辑基础信息、维护完整档案、地图定位和更多操作；传感器名称进入只读档案。观测能力管理提供编辑观测能力、维护完整档案和地图定位。地图抽屉对传感器显示编辑基础信息、编辑观测能力、维护完整档案和地图定位。

入口通过 `/resources/sensors` 的 `sensorId`、`section`、`mode` 查询参数定位。来自 Agent 任务的 `runId`、`returnTo`、`currentTab` 会继续透传，返回任务页面时不丢失业务上下文。

## 编辑体验

- 每个分区拥有独立草稿；切换分区前会提示未保存修改。
- 保存成功后重新读取后端数据，页面显示的是服务端回显。
- 只读模式不显示保存按钮，并禁用编辑控件。
- 量测项和接入接口使用表格维护，删除需要确认，保存时一次性提交。
- 高级能力参数、空间姿态、约束和接口元数据折叠在 JSON 输入中；不填写真实凭据。

## 与任务匹配的边界

档案完整度只用于告诉用户哪些元数据已经维护。任务候选筛选仍由后端的传感器任务匹配服务判断空间、时间、分辨率、精度、覆盖率、权限和调度占用，不能用档案完整度替代任务匹配结果。
