# 卫星动态轨迹交互说明

地图加载到活动 TLE 生成的有效轨迹后，会以当前时间作为 Cesium 时钟起点并按 1 倍速自动播放。用户可以点击地图右上角工具栏中的“轨道模拟”按钮打开设置面板，在面板内暂停/恢复自动播放、回到当前时间，或切换 1 倍、10 倍、60 倍播放速度。设置面板默认收起，不再长期占用地图右下角空间。

前端每 5 分钟重新读取一次卫星 GIS 轨迹。刷新期间保留当前播放时间、播放状态和倍速，避免轨迹窗口更新时卫星跳回旧起点。轨迹接口暂时失败时继续使用上一份轨迹。

没有活动 TLE 或有效时序点的卫星只显示登记位置。右上角仍保留“轨道模拟”入口，打开后会明确提示当前没有可用的动态轨道数据；这表示数据源不具备动态轨迹，不是前端时间控件故障。

这里的“实时”是基于活动 TLE 的 SGP4 准实时预测，不等同于卫星 GPS 或载荷遥测实时回传。
